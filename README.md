# O.O.F: Automated Quality Control 🏭

## Project Overview
This deep learning capstone project builds a Convolutional Neural Network (CNN) to detect surface defects on manufactured parts, automating assembly line quality control.

## Project Structure
* `data/`: Raw and processed image datasets (not tracked by git).
* `notebooks/`: Jupyter notebooks for EDA and model development.
* `scripts/`: Python scripts for data preprocessing.
* `src/`: Core module containing CNN architectures and inference code.

## Setup Instructions
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run model training (coming soon).
